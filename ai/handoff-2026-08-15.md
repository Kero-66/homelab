## The main deliverable: `media/docs/SONARR_STRUCTURAL_AUDIT.md`

This is the durable reference — **read it in full before continuing this work**, not duplicated here. It documents three related library-structure bugs found this session, each with confirmed examples and a fix pattern:

1. **Specials that are actually movies** (belong in Radarr, not Sonarr) — full cross-reference table of 92 movie-length Sonarr specials against Radarr, split into Verified/Needs-manual-check/Not-movies.
2. **Whole series/seasons that duplicate another series** (VOTOMS 98/99/100 → 97, Macross Dynamite 7 → Macross 7, Tekkaman Blade II → Tekkaman Blade S2) — all three confirmed and fixed. Includes a standing **priority policy** for this pattern: try the standalone series first, fall back to the parent-series season only if that fails, actual grab success overrules preference.
3. **Recap/alternate-cut specials** — different title, same underlying content as something already owned (VOTOMS "Stage I-IV", confirmed via word-overlap with owned season episodes).

Also contains a **6-step reusable per-series workflow** (pull full season breakdown → triage Season 0 by runtime → check Radarr/TMDB directly for movie-length items → web-research if TMDB is empty → document immediately with sources → only actively grab what survives triage) — validated end-to-end on the Macross cluster this session (series 70, 73 both fully resolved using it). **Follow this workflow for the next series**, don't reinvent it.

**Known gotcha noted in the doc**: `WebFetch` cannot fetch Reddit URLs directly — use `WebSearch` for Reddit content, or find an alternate source (Wikipedia, wiki, TheTVDB) and `WebFetch` that instead.
